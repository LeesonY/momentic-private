# 需求规格说明书（SRS）

版本 1.0；2026-10-02。产品：LocalQA。面向多人使用的内网 Linux 平台，允许经配置的外部模型调用。

## 1. 产品目标和成功标准

用户输入一个可访问 URL，无需编写自动化代码，系统在限定范围和预算内理解页面、生成冒烟用例、执行检查、复现疑似问题，提供可审查的测试结论与证据。

P0 成功标准是完成真实执行闭环：输入网址→产生可读计划→执行浏览器操作→记录依据→独立复现→生成报告。URL 本身只能支撑一般页面与交互冒烟，不能自动提供金额、权限、审批等业务规则；涉及这些规则时必须使用用户给出的预期、项目知识或固定用例。

## 2. 角色与使用环境

| 角色 | 权限和典型任务 |
| --- | --- |
| 平台管理员 | 初始化部署、管理用户/模型服务/全局额度；敏感操作记审计 |
| 项目 owner | 管理成员、环境、认证资料、项目知识、运行策略与保留期 |
| 项目 operator | 在获准环境执行、停止、补充信息、查看报告和提出审查决定 |
| 项目 viewer | 查看获准项目的运行、报告和脱敏证据；不能启动、改配置或取认证材料 |

浏览器端支持主流桌面 Chromium，界面默认简体中文，测试内容可中英文混合。生产服务器为 Linux；内网 DNS、VPN/代理和目标站点访问能力由部署环境提供。跨项目不能依靠 URL 隐藏实现隔离。

## 3. 核心用户旅程

### J-01 只输入 URL

1. 用户进入项目，粘贴 URL 并点击“开始冒烟”；高级参数可不填。
2. 系统检查模型配置、项目权限、目标范围和浏览器可用性；不自动要求编写测试计划。
3. 探索有限页面，生成去重后的用例，每条列出预期来源和可检查条件。
4. 实时展示阶段、任务、操作、用例状态和剩余预算；完成的结果先显示。
5. 对疑似功能问题，在全新浏览器上下文尝试复现；超出预算的项目保留待复现状态。
6. 报告明确列出通过、发现问题、受阻、不确定及未执行项，提供证据和导出。

### J-02 需要登录的系统

预选环境及认证配置时自动进行认证。未提供认证而入口明显受保护时请求选择认证配置；公共区域仍可测试的情况下先检查公共区域并列出受阻项。登录失败、MFA、验证码或角色不足不直接判为产品 Bug。支持 AI 登录（按自然语言登录说明和变量名自行完成多步登录，模型不接触变量值；默认推荐）、表单认证（AI 识别字段或固定定位器）和合法上传的 storage state；需要人在远程浏览器完成的复杂 SSO/CAPTCHA 在 P0 标为受阻，交互接管属于 P2。

### J-03 范围补充与停止

用户可在运行页补充测试说明、预期或排除路径；系统记录上下文版本，在操作边界应用。当前已完成结果保持历史，不因新说明重写为通过。停止后不派发新浏览器/模型任务，正在进行的操作收到取消信号，保留部分报告并完成有限清理。

### J-04 问题审查与修复交接

用户查看期望、实际、必要步骤及证据，明确选择审查结论。提交、接受/关闭等改变问题状态的动作须先展示具体内容或目标并由人确认。导出的问题描述保留换行，不含服务器本地路径或认证内容。P0 不自动提交外部 Bug 系统。

## 4. 功能需求

表内每个 ID 是开发任务和验收的追踪单位。P0 交付不能用模拟结果替代真实浏览器与模型执行。

### 4.1 多用户与项目

| ID | 优先级 | 要求与验收要点 |
| --- | --- | --- |
| FR-001 | P0 | 本地账号登录、退出和过期会话；管理员完成一次初始化；普通页面请求不暴露密码或密钥 |
| FR-002 | P0 | 项目成员分 owner/operator/viewer；API、SSE、下载和导出统一鉴权；跨项目 ID 请求被拒绝 |
| FR-003 | P0 | 新建/归档项目；归档后不可新建运行，既有报告按权限保留；危险变更有具体预览和审计 |
| FR-004 | P0 | 创建环境：Base URL、允许 origins/路径、TLS 策略、代理引用、默认认证、运行额度；配置快照随每次运行保存 |
| FR-005 | P0 | 保存项目知识文本、业务规则和禁止操作；记录作者和版本；运行使用固定快照，模型不能自行修改已审查规则 |

### 4.2 模型与认证

| ID | 优先级 | 要求与验收要点 |
| --- | --- | --- |
| FR-006 | P0 | 管理员配置模型服务及 model ID；支持后端 OpenAI-compatible 适配接口；能力探测包含 JSON、工具、图片、错误/超时处理 |
| FR-007 | P0 | Planner/Executor/Assertion 可配置不同模型；默认可共用一种；记录实际模型标识、适配器与提示版本、用量来源 |
| FR-008 | P0 | 外部模型模式有明确的数据去向，密钥仅后端解密；禁止未配置的外部 fallback；内部模型作为同一适配接口候选 |
| FR-009 | P0 | 认证配置支持 none/form/storage_state；secret write-only；表单认证有成功条件；状态只在获准 origin/角色内复用 |
| FR-010 | P0 | 认证缺失/失效请求输入或标为受阻；临时验证码只供固定字段填充，不进模型、数据库正文和导出；复杂人工认证不假装通过 |

| ID | 优先级 | 要求与验收要点 |
| --- | --- | --- |
| FR-017 | P0 | Playwright 真浏览器执行；不同任务隔离 context，auth state 仅来自获准配置；iframe、弹窗及下载在支持边界内记录 |

| FR-034 | P0 | 运行页显示任务、用例、问题、进度、预算与简短决策摘要；不要求保存或展示模型原始隐藏推理 |

## 5. 默认行为和支持边界

### 5.1 smoke 预设（必须统一）

| 配置 | 默认 | 可配置范围/规则 |
| --- | ---: | --- |
| maxCases | 8 | 1–30 |
| maxPages | 6 | 1–30 |
| maxDepth | 2 | 0–5 |
| maxActiveSeconds | 600 | 60–3600；不包括人工输入等待，输入等待另限 300 秒 |
| maxActionsPerCase | 12 | 1–30 |
| maxActions | 120 | 10–1000，跨探索/执行/复现共享 |
| maxModelCalls | 100 | 1–500；每个真实请求/重试均计入 |
| maxReproductions | 3 | 0–10；超出保留 suspected |
| concurrency | 2 | 不超过项目及平台配额；P0 平台默认 4 |
| maxTotalTokens | 300000 | 包含输入/输出；缺少服务方用量时保守估算并标记 |
| actionPolicy | non_submitting | 默认不提交业务表单、变更配置或进入未知副作用动作 |

URL 超出允许范围、模型未配置、浏览器不可用等前提失败在派发前返回具体错误；仅输入 URL 时用其 origin 作为本次临时目标范围，仍受项目管理员配置限制。模型请求等待、浏览器等待和重试都消耗 active 时间。

### 5.2 边界

- Web 首期 Chromium，桌面视口默认 1440×900；移动 viewport 可另设，但原生移动端属 P2。
- iframe/新标签页须在允许范围内。跨域内容不可取得时标为受阻，不假定验证完成。
- 未接入 WebSocket、复杂 canvas、PWA 或第三方 SSO 的检查，可以记录观察但不能冒称已完整验证。
- P0 不允许用户脚本/插件任意执行服务器代码；运行中不连接用户 Mac 的私人浏览器配置。
- 默认避免表单提交不等于对任何站点绝对无副作用；已知自动保存/GET 写入路径应配置禁止规则，未知动作记录跳过。

## 6. 非功能需求

| ID | 要求 | 验收定义 |
| --- | --- | --- |
| NFR-001 | 正确区分结果 | 每条结论引用验收条件和证据；未知业务预期、受阻和预算未完成不得标通过 |
| NFR-002 | 数据隔离 | 项目级 API/SSE/证据隔离；模型 key、密码、cookie/token 不进入普通日志、模型正文和导出 |
| NFR-003 | 私有部署 | 运行、浏览器、数据库及证据内网托管；只有配置的模型/API 和获准目标可出网；无需 Momentic/Trigger.dev SaaS |
| NFR-004 | 并发和公平 | 参考部署 16 vCPU/32 GiB、4 个浏览器槽位、10 个在线用户；配额排队，不承诺未测性能 |
| NFR-005 | API/事件响应 | 参考环境下非长任务 API P95 ≤500 ms；事件持久化到 UI P95 ≤2 s；不包含模型与被测站响应时间 |
| NFR-006 | 取消 | 接受取消后 ≤2 s 停止新任务派发；≤30 s 终止残留执行进程；清理/最终报告最长另 60 s；第三方已计费请求不保证退款 |
| NFR-007 | 恢复 | API 重启不丢已提交结果；Worker 心跳 10 s、租约 45 s，失联 ≤60 s 被检测；浏览器动作不能承诺 exactly-once |
| NFR-008 | 可观察 | 每个运行/任务/动作/模型请求可关联；错误码稳定，日志可脱敏排查；预算实际/估算来源明确 |
| NFR-009 | 运维 | 有健康、就绪、版本、迁移、备份/恢复、磁盘容量和清理状态；恢复过程实测，不仅写脚本 |
| NFR-010 | 保留 | 默认报告 90 天、二进制证据 30 天、审计 180 天；可配置；不删除运行中的材料及人工保留项 |
| NFR-011 | 证据容量 | 默认单 artifact 25 MiB、单运行 250 MiB；超限降级并显式记录；不静默截断影响关键判定的材料 |
| NFR-012 | 可维护 | 共享版本化契约、迁移、固定测试模型和受控 fixture；新增 provider/工具必须通过能力与策略验证 |

这些指标是目标，最终通过验收报告记录硬件、模型、依赖版本、样本量及偏差，不以局部演示宣称全面达标。

## 7. 页面与交互规格

| 页面 | P0 内容 |
| --- | --- |
| 登录/初始化 | 初始化完成状态、登录、会话失效；不将后端错误堆栈给普通用户 |
| 项目首页 | URL 输入、可选说明、环境/认证/模型选择、高级额度、外部模型数据提示、开始按钮 |
| 运行工作台 | 左侧历史与筛选；中间说明/输入请求与阶段；右侧任务/用例/问题/证据标签；随窗口缩小可折叠 |
| 用例详情 | 前提、步骤、验收来源、执行结论、覆盖缺口、关联动作和证据 |
| 问题详情 | 功能/静态类型、suspected/confirmed、复现情况、期望实际步骤、人工审查预览确认 |
| 环境/认证 | 允许范围、TLS/代理、认证配置、write-only 密钥、测试数据策略和默认额度 |
| 项目知识 | 文本、版本、作者、启用状态；运行采用快照 |
| 模型管理 | 提供方、模型、能力、可用状态、额度、外部数据去向；只有管理权限可编辑 |
| 项目成员/运维 | 权限、审计、容量、运行槽位、健康及配置错误 |

前端不得用永久“测试中”动效代替状态。事件断线显示“正在重连”，后台运行保持原状态；应用刷新后恢复位置和选中项。空列表、认证失败、无权限、证据缺失、模型错误、预算用尽及部分报告都须有专门状态。

## 8. 本次交付的限制

本规格基于账号只读探测、官方文档与发布包，不包含真实业务自动化验证。服务端内部数据库和调度实现仍未知；这里定义的是 LocalQA 的实现契约。开发期间必须使用本项目新建的受控 fixture 和唯一测试数据，不能未经授权将现有真实业务站点作为写入测试靶场。
