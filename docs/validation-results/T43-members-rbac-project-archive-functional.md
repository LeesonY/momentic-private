# T43 产品功能交付：成员角色管理与项目归档

日期：2026-10-10。项目：`E:\\AI\\momentic`。
本阶段继续交付可操作的产品功能，不开展性能/压力/Soak，
不调用付费模型、不部署生产环境。

## 交付

- “成员/运维”页从只读成员表升级为真正的项目授权操作界面。
  项目负责人及平台管理员可以添加已有账号、分配
  owner/operator/viewer 角色、修改和移除其他成员。
  普通成员只读；项目归档后写入操作隐藏。
- 管理员可从有权限访问的平台用户目录选择已有账号；
  项目负责人非平台管理员时可输入已有账号 UUID。
  不是创建新用户的入口，不在 Web 侧扩大用户目录可见范围。
- 成员变更先在页面草稿中审核；禁止移除当前操作账号，
  阻止保存没有 owner 的列表，要求显式确认完整成员替换。
  服务器仍执行正式 `members.write` 权限与至少一位 owner、
  不重复成员、PostgreSQL 项目版本的并发校验。
- 成员超过分页上限时不允许整体替换，避免删掉未加载的用户；
  成员保存失败不伪报成功，增加“重新加载成员和项目版本”
  以恢复版本冲突。
- 在成员/运维页新增项目归档操作：项目名称完全匹配和复选框
  二次确认、禁止存在待保存成员变更时归档，使用
  `PATCH /api/v1/projects/{projectId}` + `expectedVersion`。
  返回合法的已归档 Project 后更新全局选择器并回到首页。
  归档项目选择器显示状态，不能再启动新冒烟运行。
- 原成员/运维页固定时间戳和 Mock 人物的“审计历史”已移除；
  当前未提供真实可查的审计接口，因此明确说明未接入，
  不再以模拟历史伪装成真实审计事件。
- 无健康响应时显示“状态未知/尚未获取”，不再凭空显示
  服务不就绪或某个固定版本。
- 离线 Mock 客户端的项目成员替换现在更新 Mock 状态与项目版本，
  不再始终返回同一旧 Project。
