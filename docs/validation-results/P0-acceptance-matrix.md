## T09-B 必须补齐的最小集合

1. **六服务成堆运行**（gateway/web/api/orchestrator/worker/postgres）——T09-B1 的镜像是前提，尚未成堆跑过。
2. **多用户与配额**：10 在线用户、4 浏览器槽位下的排队与公平性；三级限制实测（AC-001/006）。
3. **故障注入**：DB 重启、worker 崩溃、磁盘满、SSE 断线、凭据撤销（AC-015 与 docs/04 第 5 节故障表）。
4. **性能**：非长任务 API P95 ≤500ms、事件落库到 UI P95 ≤2s（NFR-005）。
5. **UI 端到端**：刷新恢复、断线重连、partial/受阻状态的真实截图（AC-013）。
6. **代理层 SSE 实测**：确认 nginx 不缓冲（配置已按契约路径修正，但未在真实代理后验证）。
