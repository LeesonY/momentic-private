5. **UI 端到端**：刷新恢复、断线重连、partial/受阻状态的真实截图（AC-013）。
6. **代理层 SSE 实测**：确认 nginx 不缓冲（配置已按契约路径修正，但未在真实代理后验证）。

## 判定归属的教训（写给自己与接手者）

这一项排查中出现过四次结论，只有最后一次完整：①怀疑旧镜像 → ②判"产品渲染缺陷" → ③"容器服务路径错位"（属实并已修） → ④"注入窗口 < 工作台打开耗时"（最终）。根因是**结论没有建在正确的层上**：判断"产物是否最新"必须查**被服务的那份**而非磁盘上的那份；判断"UI 是否渲染"必须在**真实浏览器**里看 DOM 而非读源码或 bundle。

同样地，本会话出现过一次**假阳性**：agy 在 vite 开发服务上验证 UI 通过（P95 169ms），但生产构建下不成立。**前端验收必须在交付产物上做。**
