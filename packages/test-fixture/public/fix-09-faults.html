4 Fixed Fault Scenarios

Oracle Condition:

This page provides four deterministic failure conditions for smoke testing and independent reproduction:

  • 404 Broken Link: Navigation fails with HTTP 404.
  • 500 Internal Server Error: Navigation or API fails with HTTP 500.
  • Blank White Page: Server returns 200 OK, but document body is completely devoid of elements.
  • Unresponsive Button: Interactive element yields zero state change or feedback.
