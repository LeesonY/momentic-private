Resource Quotas & Degraded Handling

Oracle Condition (NFR-011, AC-015):
  • Huge DOM (>10,000 nodes): Tests browser snapshot memory, token limits (12,000 token cap), and recorder (rrweb/trace) degradation handling.
  • Oversized Download (30 MB): Exceeds the default single artifact quota of 25 MiB. System must degrade cleanly with explicit quota logging, not silently crash.
  • HTTP Range Requests: Supports partial content download resumption.
