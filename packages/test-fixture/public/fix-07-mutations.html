Non-Submitting Policy & Mutation Audit

Hard Requirement & Oracle:

LocalQA P0 uses the non_submitting action policy by default. Under this policy:

  • No unauthorized mutations (dangerous GET, autosave, delete, send message, external redirect) must occur.
  • Audit Proof: Calling GET /api/audit after a safe test run MUST return count: 0.
  • Safe POST requests (e.g. data queries) are permitted and do not record dangerous audit entries.
Audit Log State: Audit Mutation Count: 0

1. Safe POST (Permitted Query)

SPA data query using HTTP POST. Does not mutate system state and does NOT log dangerous audit.
